# VPN для Android

Здесь публикуются сборки Android-приложения нашего VPN-сервиса. Подключение работает только
с подпиской, которую выдаёт администратор сервиса.

## Установка

1. Скачайте последнюю версию:
   [vpnapp_universal.apk](https://github.com/FriedCerebrum/vpn-client-releases/releases/latest/download/vpnapp_universal.apk)
   (подходит для любого телефона и Android TV). Отдельные файлы под архитектуру процессора
   лежат на странице [релизов](https://github.com/FriedCerebrum/vpn-client-releases/releases/latest).
2. Откройте файл и разрешите установку из этого источника, если Android спросит.
3. Откройте ссылку на подписку, которую вам прислали: приложение добавит её само.

Дальше приложение обновляется само: раз в 12 часов проверяет эту страницу и предлагает
установить новую версию. Обновление ставится поверх, подписка и настройки сохраняются.

Требуется Android 7.0 или новее.

## Проверка файла

К каждому релизу приложен `SHA256SUMS`. Все версии подписаны одним ключом: Android не даст
установить обновление, подписанное чужим ключом.

## Приватность

Что приложение собирает для диагностики подключения и что не собирает:
[PRIVACY.md](PRIVACY.md). Диагностика включается только с вашего согласия при первом запуске.

## Исходный код и лицензия

Приложение основано на открытом проекте [v2rayNG](https://github.com/2dust/v2rayNG) и, как
он, распространяется по лицензии [GPL-3.0](LICENSE). Полный исходный код каждой версии
приложен к её релизу (`vpnapp-<версия>-src.tar.gz`).
